# AI_USAGE — Практична робота №4

Генеративний ШІ використовувався для коду notebook, класу політики, тестів і чернетки звіту.

## Task 1 — теоретичний поріг (обов'язковий аудит)

**Task:** визначити поріг для сценарію `c_FP = 1, c_FN = 5`.
**Proposal:** використати теоретичний поріг `t* = c_FP / (c_FP + c_FN) = 1/6 ≈ 0,167`.
**Assumptions in the proposal:** бали калібровані; вартості сталі для всіх пасажирів; **немає обмеження на кількість дій**; розподіл даних не зміниться.
**Verification:** формулу перевірено через порівняння умовних ризиків двох дій (`c_FP(1−p) ≤ c_FN·p`). Калібрування перевірено діаграмою і Brier (0,1428). Емпіричний мінімум на OOF — 0,19, але він вимагає супроводу 84,6% пасажирів при місткості 50%.
**Decision:** змінено — третє припущення не виконується, тому вибрано мінімум вартості серед допустимих точок, `t = 0,71` (`results/scenarios.csv`, `results/candidate_policies.csv`).

## Task 2 — калібрування

**Task:** покращити ймовірності моделі.
**Proposal:** застосувати isotonic-калібрування, бо воно гнучкіше.
**Decision:** змінено на sigmoid: 712 об'єктів train і по ~380 об'єктів на внутрішній fold — мало для isotonic; після перевірки sigmoid теж не дав покращення, тому фінальна політика використовує некалібровані бали.
**Verification:** OOF Brier 0,1428 в обох варіантах, ROC-AUC 0,8530 / 0,8527 (`results/calibration.csv`).

## Task 3 — вартість помилки

**Task:** запропонувати значення `c_FN`.
**Proposal:** оцінити FN як «вартість людського життя» у грошах.
**Decision:** відхилено. ШІ не є джерелом реальної вартості; використано лише сценарні відношення 1:1, 1:5, 1:20 і неперервну чутливість 1…30 (`results/sensitivity.csv`).

## Task 4 — тести політики

**Task:** згенерувати тести для класу з двома порогами і top-k.
**Proposal:** 8 тестів для порогів.
**Decision:** розширено до 18: додано NaN, поріг поза [0, 1], одно-порогову політику, узгодженість `policy_config.json` з кодом і 6 тестів top-k (порожня партія, n < k, ties, відтворюваність, некоректні аргументи).
**Verification:** `python -m unittest -v tests/test_decision_policy.py` → `Ran 18 tests ... OK`.
