# Лабораторна робота №7. Пакування та відтворення ML-компонента


## Приймання моделі

Мета — перетворити зафіксовану у ЛР6 модель Wine Quality на встановлюваний Python-пакет із перевірюваним контрактом. Вхідний комплект включає логістичну регресію, схему 11 полів, рішення про вибір, контрольні ID, метрики та приклад прогнозу. Зіставлено SHA-256 кожного обов’язкового файла до завантаження моделі. Артефакти походять із довіреного репозиторію курсу; хеш підтверджує цілісність відносно зафіксованого manifest.

## Шлях запиту

CLI приймає JSON і передає його Predictor. Валідатор звіряє точний набір полів, типи і скінченність та впорядковує значення за схемою. Невідоме або відсутнє поле, текст, bool, NaN та нескінченність блокують виклик. Число поза навчальним діапазоном повертає попередження. Pipeline застосовує медіанну імпутацію та стандартизацію з ЛР6. У відповіді є ймовірність якості ≥ 7, клас, поріг 0,5, версії та попередження. Ліміт пакета — 64 записи включно.

|Операція|Вхід|Результат|
|---|---|---|
|metadata|Без запису|Версія, сімейство, хеш і параметри рішення|
|validate|Один JSON-об’єкт|Ознака коректності та попередження|
|predict|Один JSON-об’єкт|Один прогноз|
|predict-batch|Масив з 1–64 об’єктів|Прогнози у вхідному порядку|

## Відтворення без пошуку

Повторно навчено саме зафіксовану конфігурацію за початковими 1087 train ID. Для всіх 272 незалежних записів порівняно імовірності наданої й відновленої моделей із заздалегідь заданим абсолютним допуском 10⁻¹⁰. Файл results/reproducibility.json містить максимальну різницю й обидві AP. Порівняння перевіряє відтворюваність і не змінює параметри рішення. Контрольна AP становить 0,3793. Пакет із тестами та карткою моделі заархівовано у handoff.zip, розпаковано й перевірено повторно. Для ЛР8 передається локальне inference-ядро. Придатність до роботи на винах інших регіонів ще потребує перевірки.

## Відтворення

З кореня репозиторію для Linux/macOS і Windows PowerShell однаково: `python -m pip install ./lab07`, `python -m ml_project.cli metadata`, `python -m ml_project.cli predict lab07/src/ml_project/assets/request.json`, `python -m ml_project.cli predict-batch lab07/src/ml_project/assets/batch.json`. При помилці CLI пише у stderr та повертає код 2. Для експерименту встановіть `lab05/requirements.txt`, запустіть `python -m lab07.build` і `python -m pytest -q lab07`. Окреме чисте середовище створюється командою `python -m venv .venv`. Активація: `source .venv/bin/activate` або `.venv\Scripts\Activate.ps1`.
