# ПР6. Аудит кластерів ЛР5

З кореня виконайте `python -m pip install -r practical06/requirements.txt`, `python -m practical06.main` та `python -m pytest -q practical06`. Використовуються збережені моделі та стабільні ID з ЛР5. Повторно q, K і пороги не підбираються. 15 карток і 123 записи ролей доступні у results. Кластер 9 містить лише два унікальні train ID, тому для кожної ролі наведено обидва. Правила позначили 108 із 468 випадків при місткості 70. Для архівіста рекомендовано пріоритетну ручну чергу, автоматичне видалення відхилено.
