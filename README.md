# Основи машинного навчання

Навчальний репозиторій для практичних і лабораторних робіт із дисципліни «Основи машинного навчання».

## Організація репозиторію

```text
.
├── data/                  # дані та описи їх джерел
├── src/                   # спільний відтворюваний код
├── practicalXX/           # практичні роботи
├── labXX/                 # лабораторні роботи
├── requirements.txt       # зафіксовані Python-залежності
└── README.md
```

Кожна робота зберігається в окремій директорії. Її `README.md` містить постановку задачі, опис даних, план, результати, аналіз і висновки. Ноутбуки зберігаються виконаними, а графіки — окремими файлами у `figures/`.
